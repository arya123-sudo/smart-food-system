# Smart Food Intelligence & Waste Optimization System

## Overview

The Smart Food Intelligence & Waste Optimization System is a DBMS mini project developed using PHP, MySQL, HTML, CSS, and JavaScript. The system helps users manage household food inventory, monitor expiry dates, track food waste, and analyze waste data efficiently.

## Features

* User Registration & Login
* Dashboard Analytics
* Add Food Items
* Inventory Management
* Search Food Items
* Edit & Delete Food Items
* Expiry Alert System
* Waste Log Management
* Waste Analytics with Charts
* Session Management

## Technologies Used

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* Chart.js
* XAMPP

## Database Tables

* USER
* HOUSEHOLD
* FOOD_ITEM
* CONSUMPTION_LOG
* WASTE_LOG
* SHOPPING_LIST
* NOTIFICATION

## How to Run

1. Install XAMPP
2. Start Apache and MySQL
3. Place project folder inside htdocs
4. Import database into phpMyAdmin
5. Open localhost/smart-food-system
